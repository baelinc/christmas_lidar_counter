# What's new

## 1.1.0
- **Wi-Fi tab:** switch Wi-Fi on or off, scan for networks and join one from the web page.
- **Lane chooser:** say whether the lane closest to the sensor is coming in or leaving, then count either lane or both.
- **Choose Ethernet or Wi-Fi** for reaching the BaldrickSignals board and the Falcon Player.
- **Only upload nights with a show:** skip nights when the Falcon Player never played.
- **Updates tab:** the page now checks GitHub for new versions and can install them for you, with an automatic return to the old version if the new one does not start.
- **Automatic restart:** optionally restart the Pi every night, every other day or weekly at a time you choose.
- A watchdog restarts the settings page by itself if it ever stops answering.

## 1.0.0
- First release: lidar car counting on a Raspberry Pi or similar board, web page, website upload, BaldrickSignals crowd board.
